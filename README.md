## 각 자료 소개

### 📚 개혁주의 신학 자료실 (Theology)

- **허먼 후크세마 『The Triple Knowledge Vol. 2』 전용 웹 리더** — 하이델베르크 교리문답 강해 대작 Vol. 2(Lord's Days 17~31)의 752쪽 분량을 Lord's Day 단위 목차와 본문 검색으로 읽는 1.5MB 자체 완결형 리더. `index.html` 파일 하나만으로 오프라인에서도 동작합니다.
- **하이델베르크 교리문답과 교회의 미래** — 1563년 교리문답의 작성 역사, 구조, 그리고 400년이 넘는 세월이 오늘의 교회와 교육에 주는 교훈을 정리한 강해 자료.

### 🤖 AI & 미디어 테크 연구실 (AI & Media Lab)

- **OBS 마이크 오디오 정밀 진단기** — 녹음 파일을 분석해 음압 분포·잡음·말끝 끊김을 진단하고 ReaGate(노이즈 게이트) 세팅 처방까지 제안하는 PC 웹 도구.
- **AI 활용 가이드** — 목회 현장에서 AI를 활용하는 방법을 안내하는 별도 리포지토리(https://happy1ch.github.io/ai-guide/).
