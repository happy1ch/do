# The Triple Knowledge Vol. 2 — 웹 리더

허먼 후크세마(Herman Hoeksema)의 대작 『The Triple Knowledge: An Exposition of the Heidelberg Catechism』 **Vol. 2**를 위한 전용 웹 리더입니다.

- **대상**: Vol. 2 — Lord's Days 17~31 (그리스도의 승영, 성령 강림, 성령과 교회, 용서와 칭의, 은혜의 수단: 성례전 등)
- **주소**: https://happy1ch.github.io/do/ (GitHub Pages)

## 사용법

리포지토리의 `index.html`이 곧 리더 그 자체입니다(1.5MB 자체 완결형, 별도 데이터 파일 불필요).

- **웹에서**: 위 주소로 접속하면 바로 열립니다.
- **오프라인으로**: `index.html` 파일 하나를 브라우저에서 열면 됩니다.

## 기능

- 사이드바 목차: Lord's Day 단위 이동
- 본문 검색
- 페이지 단위 읽기(페이지 번호 이동)
- 다크 모드
- 독서 위치 기억

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 웹 리더 본체 (전체 본문 내장) |
| `The_Triple_Knowledge_Vol2_Hoeksema.txt` | 원문 텍스트 (리플로우용 원본, 1.4MB) |
